# SOC 2 Sample Control Testing Workpaper

**Project Type:** Simulated SOC 2 Type II Audit  
**Control Domain:** Logical and Access Controls  
**Control ID:** AC-01  
**Assessment Type:** Sample Control Testing

## 1. Control Objective

Ensure that access to organizational systems and sensitive information is restricted to authorized personnel based on their job responsibilities.

## 2. Control Description

Management reviews user access rights periodically to ensure that employees retain only the access necessary to perform their assigned responsibilities.

## 3. Risk

Unauthorized or excessive user access may result in data breaches, unauthorized transactions, or exposure of confidential information.

## 4. Audit Procedures

1. Obtain the user access listing for the selected system.
2. Obtain evidence of the latest periodic access review.
3. Verify that the review was performed by an authorized individual.
4. Check whether inappropriate or unnecessary access was identified.
5. Verify that identified access issues were appropriately remediated.
6. Document exceptions, if any.

## 5. Sample Evidence Reviewed

*Illustrative evidence for this simulated exercise only.*

- User access listing
- Access review approval record
- Employee role and responsibility listing
- Access removal confirmation

## 6. Testing Results

| Test Attribute | Illustrative Result |
|---|---|
| Access listing obtained | Yes |
| Review performed | Yes |
| Reviewer authorized | Yes |
| Exceptions identified | 1 |
| Remediation evidence available | No |

## 7. Audit Observation

One user account was identified with access that was no longer required for the employee's current responsibilities. Evidence of access removal was not available at the time of testing.

## 8. Conclusion

**Result: Exception Identified**

The control requires further attention because inappropriate access was identified and remediation could not be verified.

## 9. Recommendation

Management should investigate the identified access issue, remove unnecessary access, retain remediation evidence, and strengthen periodic access review procedures.
