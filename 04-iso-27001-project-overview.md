# ISO/IEC 27001:2022 – Internal Control Assessment Portfolio Project

## Project Overview

This portfolio project demonstrates a structured approach to assessing selected information security controls based on ISO/IEC 27001:2022 Annex A.

The project uses a fictional organization, **ABC Technologies Ltd.**, to illustrate how an information security control assessment can be planned, documented, evaluated, and followed up.

**Important:** This is a simulated portfolio exercise. It does not represent an actual client audit, verified audit evidence, or an ISO certification assessment.

## Project Objectives

- Demonstrate understanding of ISO/IEC 27001:2022 Annex A controls.
- Document control objectives, risks, and expected activities.
- Develop practical audit procedures and evidence requirements.
- Illustrate sample-based control testing and assessment documentation.
- Identify hypothetical control gaps and recommend corrective actions.
- Demonstrate risk assessment and audit reporting skills.

## Assessment Scope

The simulated assessment covers six selected Annex A controls:

| Control | Area |
|---|---|
| 5.15 | Access Control |
| 5.18 | Access Rights |
| 5.23 | Information Security for Use of Cloud Services |
| 8.2 | Privileged Access Rights |
| 8.13 | Information Backup |
| 8.15 | Logging |
