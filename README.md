# GRC & Information Security Audit Portfolio

Practical portfolio demonstrating IT audit, Governance, Risk & Compliance (GRC), information security control testing, risk assessment, and audit documentation.

## About This Portfolio

This portfolio contains practical and illustrative projects demonstrating audit methodologies, control assessment approaches, risk identification, evidence evaluation, and audit reporting techniques.

The projects are designed to showcase practical knowledge of IT audit, Information Security, SOC 2, and ISO/IEC 27001.
